## Задача 2 — RKN-устойчивость (Cloudflare перед VPS)

### Проблема
Прямые запросы из RU-браузеров на IP `217.76.49.47` могут быть заблокированы РКН. Нужно спрятать реальный IP за Cloudflare.

### Решение: Cloudflare CDN Proxy (бесплатный тариф)

**Как работает:**
```
Браузер (RU) → Cloudflare Edge (глобальные IP) → VPS 217.76.49.47
```
Cloudflare IP (~104.x.x.x) не блокируются РКН — на них завязаны миллионы сайтов.

**Шаги:**

**2.1** Зарегистрировать домен `uni.ai` в Cloudflare (или добавить зону, если домен уже есть).

**2.2** В DNS Cloudflare создать запись:
```
Type: A
Name: proxy
Content: 217.76.49.47
Proxy status: Proxied (оранжевое облако ✓)
TTL: Auto
```
Это главный шаг — оранжевое облако скрывает реальный IP.

**2.3** В Cloudflare: SSL/TLS → режим **Full** (не Full Strict).
- Между браузером и Cloudflare — сертификат Cloudflare
- Между Cloudflare и VPS — сертификат Let's Encrypt

**2.4** Cloudflare → Security → настроить:
- Bot Fight Mode: ON
- Browser Integrity Check: ON
- Security Level: Medium

**2.5** Nginx на VPS — добавить реальные IP клиентов через заголовок Cloudflare:
```nginx
# В /etc/nginx/sites-available/uni-proxy добавить в server block:
set_real_ip_from 103.21.244.0/22;
set_real_ip_from 103.22.200.0/22;
set_real_ip_from 103.31.4.0/22;
set_real_ip_from 104.16.0.0/13;
set_real_ip_from 104.24.0.0/14;
set_real_ip_from 108.162.192.0/18;
set_real_ip_from 131.0.72.0/22;
set_real_ip_from 141.101.64.0/18;
set_real_ip_from 162.158.0.0/15;
set_real_ip_from 172.64.0.0/13;
set_real_ip_from 173.245.48.0/20;
set_real_ip_from 188.114.96.0/20;
set_real_ip_from 190.93.240.0/20;
set_real_ip_from 197.234.240.0/22;
set_real_ip_from 198.41.128.0/17;
real_ip_header CF-Connecting-IP;
```
Нужно чтобы rate-limit работал по реальному IP пользователя, а не IP Cloudflare.

**2.6** Firewall на VPS — принимать 80/443 только от Cloudflare IP:
```bash
# Устанавливаем ufw
ufw allow ssh
ufw allow from 103.21.244.0/22 to any port 80,443
ufw allow from 104.16.0.0/13 to any port 80,443
# ... остальные Cloudflare CIDR (полный список: https://www.cloudflare.com/ips/)
ufw enable
```
Теперь реальный IP VPS недоступен напрямую — только через Cloudflare.

**Почему это работает против РКН:**
РКН блокирует по IP. Реальный IP VPS скрыт. Cloudflare IPs не блокируются, т.к. за ними стоит огромная часть рунета.

## Задача 3 — VoiceAgent: блок с ElevenLabs Conversational AI

### Что это
Отдельный UI-блок рядом с DemoChat, где пользователь **разговаривает с AI в реальном времени** — двусторонний голосовой разговор. Не STT+LLM+TTS по очереди, а полноценный голосовой агент через **ElevenLabs Conversational AI API** (WebSocket, sub-second latency).

### Как это работает
```
Браузер (микрофон) ←WebSocket→ ElevenLabs Conversational AI
                                      ↓
                              GPT-5.4 (настраивается в EL dashboard)
                                      ↓
                             ElevenLabs TTS (выбранный голос)
                                      ↓
                               Браузер (динамик)
```

ElevenLabs сам управляет всем пайплайном — VAD (определение конца речи), транскрипция, LLM, синтез голоса, стриминг. Задержка ~500мс.

### Технология: `@11labs/client` SDK

Браузерный SDK ElevenLabs для Conversational AI:
```
npm: @11labs/client
```

Ключевые возможности:
- `Conversation.startSession({ agentId, overrides })` — старт сессии
- `overrides.agent.prompt.prompt` — переопределить system prompt динамически (без создания 21 агента!)
- Автоматически управляет микрофоном, аудио-плейбэком, VAD
- Коллбэки: `onConnect`, `onDisconnect`, `onMessage`, `onModeChange`
- `conversation.getInputVolume()` / `conversation.getOutputVolume()` — уровни для анимации

### Безопасность: signed URL через наш прокси

Нельзя светить `ELEVENLABS_API_KEY` на фронте. Алгоритм:

1. Фронт вызывает `GET /api/voice-token?niche=Автосервис&mode=sales`
2. Прокси-бэкенд вызывает ElevenLabs API с ключом и возвращает `signed_url`
3. Фронт передаёт `signed_url` в `Conversation.startSession()`

```
ElevenLabs API: POST /v1/convai/conversation/get_signed_url?agent_id={id}
Headers: xi-api-key: ELEVENLABS_API_KEY
→ { signed_url: "wss://..." }  // действует ~30 сек
```

#### Новый файл `proxy-backend/src/routes/voiceToken.ts`
```typescript
import { Router } from "express";
import { z } from "zod";
import { authMiddleware } from "../middleware/auth.js";
import { PROMPTS, FALLBACK_PROMPT, type Mode, type Niche } from "../lib/prompts.js";
import { voiceTokenLimiter } from "../middleware/rateLimit.js";

export const voiceTokenRouter = Router();

const QuerySchema = z.object({
  niche: z.string().optional(),
  mode: z.enum(["sales", "support", "kb"]).optional(),
});

voiceTokenRouter.get("/voice-token", voiceTokenLimiter, authMiddleware, async (req, res) => {
  const parsed = QuerySchema.safeParse(req.query);
  const { niche, mode } = parsed.success ? parsed.data : {};

  const agentId = process.env.ELEVENLABS_AGENT_ID;
  const apiKey = process.env.ELEVENLABS_API_KEY;

  if (!agentId || !apiKey) {
    res.status(500).json({ error: "voice_not_configured" });
    return;
  }

  // Получаем системный промпт для выбранной ниши/режима
  const systemPrompt =
    (mode && niche && PROMPTS[mode as Mode]?.[niche as Niche]) ?? FALLBACK_PROMPT;

  try {
    // Запрос signed URL у ElevenLabs
    const response = await fetch(
      `https://api.elevenlabs.io/v1/convai/conversation/get_signed_url?agent_id=${agentId}`,
      { headers: { "xi-api-key": apiKey } }
    );

    if (!response.ok) throw new Error(`EL error: ${response.status}`);
    const { signed_url } = await response.json() as { signed_url: string };

    res.json({ signed_url, system_prompt: systemPrompt });
  } catch (err) {
    console.error("[voice-token] error:", err);
    res.status(500).json({ error: "upstream_error" });
  }
});
```

### 3.3 Новый фронтенд-хук `src/lib/voice-agent.ts`
```typescript
// Обёртка для получения signed URL
const PROXY = process.env.NEXT_PUBLIC_PROXY_URL ?? "";
const KEY   = process.env.NEXT_PUBLIC_PROXY_KEY ?? "";

export async function getVoiceToken(niche: string, mode: string) {
  const res = await fetch(
    `${PROXY}/api/voice-token?niche=${encodeURIComponent(niche)}&mode=${mode}`,
    { headers: { "X-Internal-Key": KEY } }
  );
  if (!res.ok) throw new Error("Failed to get voice token");
  return res.json() as Promise<{ signed_url: string; system_prompt: string }>;
}
```

### 3.4 Новый компонент `src/components/VoiceAgent.tsx`

**Дизайн:** зеркалит DemoChat — тот же градиентный бордер, та же шапка с лого и ниша-дропдаун. Контентная зона вместо чата показывает голосовой UI.

**Состояния:**
- `idle` — большая кнопка "Начать разговор", пульсации нет
- `connecting` — спиннер, текст "Подключаюсь..."
- `listening` — анимированный круг (пульсирует по входному volume), текст "Слушаю..."
- `speaking` — анимированный круг (пульсирует по выходному volume), текст "ЮНИ отвечает..."
- `error` — сообщение об ошибке, кнопка повтора

**Зависимость: установить пакет**
```bash
pnpm add @11labs/client
```

**Ключевые части компонента:**

```typescript
"use client";
import { Conversation } from "@11labs/client";
import { getVoiceToken } from "@/lib/voice-agent";

// ... (те же PILLS, NicheDropdown как в DemoChat)

type AgentStatus = "idle" | "connecting" | "listening" | "speaking" | "error";

function VoiceAgentWidget() {
  const [niche, setNiche] = useState<Niche>("Автосервис");
  const [mode, setMode] = useState<Mode>("sales");
  const [status, setStatus] = useState<AgentStatus>("idle");
  const [inputVol, setInputVol] = useState(0);
  const [outputVol, setOutputVol] = useState(0);
  const [transcript, setTranscript] = useState<string[]>([]);
  const conversationRef = useRef<Conversation | null>(null);
  const volIntervalRef = useRef<ReturnType<typeof setInterval> | null>(null);

  const startConversation = async () => {
    setStatus("connecting");
    try {
      const { signed_url, system_prompt } = await getVoiceToken(niche, mode);

      const conv = await Conversation.startSession({
        signedUrl: signed_url,
        overrides: {
          agent: {
            prompt: { prompt: system_prompt },
            firstMessage: "Здравствуйте! Я AI-ассистент. Чем могу помочь?",
            language: "ru",
          },
        },
        onConnect: () => setStatus("listening"),
        onDisconnect: () => {
          setStatus("idle");
          clearVolumeInterval();
        },
        onModeChange: ({ mode: m }) => {
          setStatus(m === "speaking" ? "speaking" : "listening");
        },
        onMessage: ({ message, source }) => {
          if (source === "ai" || source === "user") {
            setTranscript((t) => [...t.slice(-20), message]);
          }
        },
        onError: () => setStatus("error"),
      });

      conversationRef.current = conv;

      // Polling объёма для анимации
      volIntervalRef.current = setInterval(() => {
        setInputVol(conv.getInputVolume() ?? 0);
        setOutputVol(conv.getOutputVolume() ?? 0);
      }, 50);

    } catch {
      setStatus("error");
    }
  };

  const stopConversation = async () => {
    await conversationRef.current?.endSession();
    conversationRef.current = null;
    setStatus("idle");
    clearVolumeInterval();
  };

  const clearVolumeInterval = () => {
    if (volIntervalRef.current) {
      clearInterval(volIntervalRef.current);
      volIntervalRef.current = null;
    }
  };

  const activeVol = status === "speaking" ? outputVol : inputVol;

  // Сброс при смене ниши/режима
  useEffect(() => {
    if (conversationRef.current) stopConversation();
    setTranscript([]);
  }, [niche, mode]);

  // Cleanup при unmount
  useEffect(() => () => { stopConversation(); }, []);

  return (
    <div className="w-full">
      <div className="rounded-[33px] bg-gradient-to-r from-accent-1 to-accent-2 p-[1px]">
        <div className="relative overflow-hidden rounded-3xl bg-accent-3">
          <div className="flex h-[520px] flex-col md:h-[620px]">

            {/* Шапка — идентична DemoChat */}
            <div className="hidden bg-bg px-4 py-3 md:block">
              {/* grid 3 cols: дропдаун | "ЮНИ.ai / статус" | лого */}
            </div>

            {/* Голосовой UI */}
            <div className="flex flex-1 flex-col items-center justify-center gap-8 px-6">

              {/* Анимированный круг */}
              <div className="relative flex items-center justify-center">
                {/* Внешние пульсирующие кольца */}
                {(status === "listening" || status === "speaking") && [1,2,3].map(i => (
                  <div
                    key={i}
                    className="absolute rounded-full border border-accent-1/30"
                    style={{
                      width: 80 + i * 40 + activeVol * 60,
                      height: 80 + i * 40 + activeVol * 60,
                      opacity: 0.6 / i,
                      transition: "width 50ms, height 50ms",
                    }}
                  />
                ))}
                {/* Основная кнопка */}
                <button
                  type="button"
                  onClick={status === "idle" || status === "error"
                    ? startConversation
                    : stopConversation}
                  disabled={status === "connecting"}
                  className={`relative z-10 flex h-20 w-20 items-center justify-center rounded-full transition-all ${
                    status === "idle" || status === "error"
                      ? "bg-accent-1 hover:bg-accent-1/90"
                      : status === "connecting"
                        ? "bg-accent-3 ring-1 ring-text/20"
                        : "bg-bg ring-1 ring-text/20"
                  }`}
                  aria-label={status === "idle" ? "Начать разговор" : "Завершить"}
                >
                  {/* иконка: Mic для idle/error, X для active, спиннер для connecting */}
                </button>
              </div>

              {/* Статус-текст */}
              <div className="text-center">
                <div className="text-[13px] font-semibold text-text">
                  {status === "idle" && "Нажмите, чтобы начать разговор"}
                  {status === "connecting" && "Подключаюсь..."}
                  {status === "listening" && "Слушаю вас..."}
                  {status === "speaking" && "ЮНИ отвечает..."}
                  {status === "error" && "Ошибка соединения"}
                </div>
                {status === "idle" && (
                  <div className="mt-1 text-[11px] font-medium text-text/50">
                    Голосовой AI-ассистент · говорите после подключения
                  </div>
                )}
              </div>

              {/* Транскрипт последней реплики */}
              {transcript.length > 0 && (
                <div className="w-full max-w-sm rounded-2xl bg-bg px-4 py-3 text-center text-[12px] font-medium text-text/70">
                  {transcript[transcript.length - 1]}
                </div>
              )}
            </div>

          </div>
        </div>
      </div>
    </div>
  );
}

export function VoiceAgent() {
  return (
    <section className="..."> {/* аналогично DemoChat section */}
      <Container>
        <SectionTitle>Голосовой AI-ассистент</SectionTitle>
        <VoiceAgentWidget />
      </Container>
    </section>
  );
}
```
