## 1. Суть проекта

**uni.ai** — маркетинговый лендинг, демонстрирующий возможности AI-сотрудника для малого бизнеса (автосервис, стоматология, юристы, фитнес и т.д.).

Ключевой элемент — **интерактивный DemoChat**: пользователь выбирает нишу (7 вариантов) и режим работы (продажи / поддержка / база знаний), после чего общается с реальным LLM, который отвечает как AI-сотрудник этой ниши. Есть голосовой ввод (Whisper STT) и голосовой вывод (ElevenLabs TTS).

### Архитектура

```
Пользователь (RU)
      │ HTTPS
      ▼
GitHub Pages — uni.ai  (Next.js 16, статический экспорт)
  └─ DemoChat.tsx
        │ HTTPS + X-Internal-Key
        ▼
Contabo VPS EU — proxy-backend  (Node.js 22, Express 5, PM2, Nginx)
  ├─ POST /api/chat        → OpenAI GPT-5.4
  ├─ POST /api/transcribe  → OpenAI gpt-4o-transcribe (Whisper)
  └─ POST /api/speak       → ElevenLabs TTS streaming
        │
        ├─→ OpenAI API
        └─→ ElevenLabs API
```

> Прямые запросы из браузера на OpenAI/ElevenLabs **запрещены** — RU IP блокирует организацию. Всё идёт через EU VPS.

## 3. Переменные окружения

### 3.1 VPS — `/root/uni-proxy/.env`

```env
# Безопасность
INTERNAL_API_KEY=<uuid-v4 — генерируется deploy-vps.sh автоматически>
ALLOWED_ORIGIN=https://uni.ai

# OpenAI
OPENAI_API_KEY=<вставить ключ из отдельного OpenAI аккаунта для демо>

# ElevenLabs
ELEVENLABS_API_KEY=<вставить ключ из elevenlabs.io>
ELEVENLABS_VOICE_ID=<ID голоса из ElevenLabs dashboard>

# Лимиты
RATE_LIMIT_WINDOW_MS=60000
RATE_LIMIT_MAX=20

PORT=3001
NODE_ENV=production
```

### 3.2 Frontend — GitHub Actions Secrets

```
NEXT_PUBLIC_PROXY_URL  = https://proxy.uni.ai
NEXT_PUBLIC_PROXY_KEY  = <тот же INTERNAL_API_KEY, что на VPS>
```

Добавляются в: GitHub repo → Settings → Secrets and variables → Actions

### 3.3 Frontend — локальная разработка `.env.local`

```env
NEXT_PUBLIC_PROXY_URL=https://proxy.uni.ai
NEXT_PUBLIC_PROXY_KEY=<INTERNAL_API_KEY>
```

## 7. Что осталось сделать ❌

### 7.1 Критично (без этого не работает)

#### A. Добавить ключи в `deploy-vps.sh` и запустить с локальной машины

Открыть файл `deploy-vps.sh`, заполнить строки:
```bash
OPENAI_API_KEY=""        # вставить sk-...
ELEVENLABS_API_KEY=""    # вставить ключ с elevenlabs.io
ELEVENLABS_VOICE_ID=""   # вставить ID голоса из EL dashboard
```
Затем:
```bash
bash deploy-vps.sh
```
Скрипт сам:
- Установит Node.js 22, PM2, Nginx, Certbot
- Скопирует proxy-backend на VPS
- Создаст `.env` с ключами
- Запустит через PM2
- Настроит Nginx (HTTP)

#### B. Настроить DNS

В DNS-панели добавить/проверить:
```
proxy.uni.ai  A  217.76.49.47
```

#### C. Выпустить SSL-сертификат (после DNS)

На VPS выполнить:
```bash
certbot --nginx -d proxy.uni.ai --non-interactive --agree-tos -m admin@uni.ai
```

#### D. Добавить GitHub Secrets

GitHub repo → Settings → Secrets and variables → Actions:
```
NEXT_PUBLIC_PROXY_URL  = https://proxy.uni.ai
NEXT_PUBLIC_PROXY_KEY  = <INTERNAL_API_KEY из вывода deploy-vps.sh>
```

#### E. Запустить деплой фронтенда

```bash
git push origin main
```
GitHub Actions автоматически соберёт и задеплоит на Pages.
